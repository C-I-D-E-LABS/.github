# Welcome to CIDE LABS!!!
### _Your games, made easy._

**C-I-D-E LABS** is a team made up of **N1ckolasGFX**, **KainCodeThings**, and a small group of outside contributors, working together on **C-I-D-Editor (CIDE)**: an engine that makes game development with HaxeFlixel easier.

Our goal is to optimize, develop, and create a modern solution that helps put Haxe and HaxeFlixel back on the map.

## What is CIDE?

CIDE is an all-in-one development environment for HaxeFlixel games. Instead of juggling separate tools, you get everything in one package:

- **The engine**, built on top of Codename Engine
- **A modern code editor** made for writing and managing game scripts
- **A built-in compiler** for building and exporting your projects
- **Tile editor and map builder** build and edit tiles for more advanced colision and maps!!
- **HScript scripting**, so you can edit gameplay and see changes without recompiling
- **CiDEScript** _(planned)_, our own scripting dialect with the `.chx` extension

## Getting Started

Install the CIDE library straight from GitHub:

```
haxelib git cide https://github.com/CIDE-Laboratory/cide
```

Then add it to your `Project.xml`:

```xml
<haxelib name="cide" />
```

Full setup steps are in the [docs]([link]).
